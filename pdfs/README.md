## 审核备注

### 《你不可不做的爱爱101式》

这是有作者、插画者、ISBN 和出版记录的商业出版物。当前文件是完整扫描版，不能因为能在网上下载，就推定可以再次公开传播。可保留为私人阅读材料，未来只提取不受版权保护的主题概念，并以自己的结构和文字重新创作。

### 《性爱516式大全》

文件几乎完全由插图组成，每页都有来源网站水印。姿势本身作为概念不等于受版权保护的表达，但具体插图、页面和整套编排可能受保护。未来可以自行绘制示意图、重新分类并原创说明，不直接使用这些页面。

### 《桃色女性潮吹教程》

这份材料暂时不适合作为医学科普来源：

- 正文称问卷比例为 23%，插图却写 37%，内部数据冲突；
- 将潮吹、女性射精、阴道分泌液和膀胱来源混为一谈；
- 把“G 点开发”与潮吹描述成近乎确定的因果关系；
- 后半部分混入具体品牌和产品宣传；
- 未提供可追溯参考文献与原始发布页面。

它可以帮助我们发现读者会问什么，但后续文章需要重新检索研究并完整重写。
