## 怎么看这张来源地图

### 访问标签

- `[免费]`：大部分内容可免费阅读或下载
- `[付费]`：以单本购买或订阅为主
- `[混合]`：同时包含免费、开放获取、试读或付费内容
- `[借阅]`：通常需要公共图书馆、学校或机构账号

### 格式说明

“格式”只记录常见情况。一本书最终提供 PDF、EPUB、网页阅读还是平台专用格式，以该书页面为准。
