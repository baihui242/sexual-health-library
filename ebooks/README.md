# Open Ebooks｜开放性健康电子书

这里收集性健康、身体、愉悦、关系、同意、避孕、生殖健康、性别与性取向相关的开放电子书。

PDF、EPUB 和网页只是阅读格式；是否属于开放资源，以原始发布页标明的许可为准。

## 授权标签

- `[Public Domain]`：公共领域
- `[CC0]`：放弃版权限制，可自由使用
- `[CC BY]`：署名后可分享、改编
- `[CC BY-SA]`：署名，改编版本需使用相同许可
- `[CC BY-NC-SA]`：署名、非商业、相同方式共享

> “Open Ebooks” 是这个栏目的简称。转载、翻译或改编时，仍要遵守每本书的具体许可；书中个别图片或引用也可能另有标注。
