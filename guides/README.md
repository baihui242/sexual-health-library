## 文章统一结构

每篇文章尽量按照下面的顺序编写：

1. **这篇解决什么问题**
2. **需要先知道的身体原理**
3. **开始前的准备**
4. **具体方法与可调整变量**
5. **如何观察自己或伴侣的反馈**
6. **常见错误与误区**
7. **安全、停止信号与就医提示**
8. **参考资料与核验日期**

## 写作原则

- 不把高潮、潮吹、进入式性行为或任何特定表现设为必须完成的目标；
- 技巧以沟通、舒适和反馈为核心，不以固定动作代替个体差异；
- 医学事实优先使用专业机构与同行评议研究核验；
- 不复制书籍、课程、网站文章或他人的插图；
- 经验性内容会明确标记为经验，不包装成普遍结论；
- 商业产品或品牌只有在确有必要时出现，并说明利益关系。
